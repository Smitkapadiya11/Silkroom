# Silk Room — silkroom.shop

Animated landing page for the Silk Room polo edit.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Launch on silkroom.shop

1. Put the WhatsApp number (country code, digits only) in `.env.local`:

```
NEXT_PUBLIC_WHATSAPP=91XXXXXXXXXX
```

2. Point the domain to the host and run:

```bash
npm run build
npm start
```

Or deploy the folder to Vercel and add `silkroom.shop` as the production domain.
